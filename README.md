# Sparkle Key（旧 RinhaBoard）

Gboard（Android版）風の自作 iOS キーボードアプリ。バージョン 0.6.3 / iOS 17+ / 未署名IPAを GitHub Actions でビルド。

- 本体アプリ: `com.aqua5624.RinhaBoard`
- キーボード拡張: `com.aqua5624.RinhaBoard.Keyboard`（アプリに同梱）

## 機能（v0.1.0）

- **QWERTY配列**（英字）。Shift 1回押し＝1文字大文字、素早く2回押し＝ Caps Lock
- **地球儀キー**：タップで次のキーボードへ、長押しでキーボード一覧（iOS標準 `handleInputModeList`）。`NeedsInputModeSwitchKey` 相当の場面でも常時表示
- **「123」の数字モードは2種類から選択可能**
  - QWERTY数字：数字1行＋記号行の横並びレイアウト（`#+=' で記号ページ2枚目）
  - テンキー：3×4の電話パッド風（1〜9、0、＋、−、記号切替つき）
  - 切り替えは本体アプリの設定 or キーボードのツールバーから即時
- **クリップボード保存**
  - キーボードを開くと今のクリップボード（テキスト）を自動で履歴に保存（重複なし、上限100件）
  - パネルからタップで貼り付け（挿入）、ピン留め、削除、ピン以外の一括削除
  - ツールバーの＋から手動保存も可能。本体アプリからも履歴の確認・追加・削除ができる
  - ※ iOSの仕様で「フルアクセスを許可」が必須。パスワード欄では自動的に標準キーボードになる
- **Gboard風ツールバー**（上部）：クリップボード開閉、言語切替、数字レイアウト切替
- **ローマ字入力＋かな漢字変換**：ツールバーの「あ」で切替。促音（っ）・撥音（ん）・拗音（きゃ 等）対応。`、`→ `、` / `.`→ `。`
  - 入力中のかなはキーボード内の候補バーに表示され、文書へは確定した分だけ入る（iOSのカスタムキーボードは入力欄側に未確定文字を出せないため）
  - **スペース**＝先頭候補を確定（残りは入力中のまま）、**候補タップ**＝その候補で確定、**✓確定**＝変換しながら全部確定、**改行**＝全部確定して改行、**✕**＝入力中を破棄
  - 変換エンジン（v0.3.0〜）: **azooKey の AzooKeyKanaKanjiConverter**（Swift Package、revision `5a9c4f6` にピン留め）。文全体の変換候補＋最初の文節の候補を候補バーに出す。選んだ候補はエンジン側で**学習**される（保存先は App Group 内の `AzooKeyData`、使えない場合は拡張の書類フォルダ）
  - v0.2.0 までは同梱辞書（Mozc 由来、約21万件）＋簡易文節スコアの自前方式だった（履歴は git 参照）
- **ユーザー辞書**（v0.3.0で追加）：本体アプリで「読み＋単語＋品詞（一般名詞／固有名詞）」を登録すると、キーボードの変換候補の**先頭**に出る。azooKey 側にも `importDynamicUserDictionary` で取り込むため、文全体の変換にも反映される
- オプション：数字行の常時表示（英字の上、Gboardと同じ設定項目）

## 有効化

設定アプリ → 一般 → キーボード → キーボード → 新しいキーボードを追加 → RinhaBoard。
続けて RinhaBoard の項目で「フルアクセスを許可」をONにする（クリップボード用）。

## 注意

- App Group（`group.com.aqua5624.RinhaBoard`）で本体アプリと履歴を共有する。再署名環境（LiveContainer等）でグループ権限が落ちる場合は、キーボード側の保存領域にフォールバックしてキーボード単体では動作する（本体アプリと履歴が連動しないことがある）。
- azooKey の辞書は Swift Package のリソースとして自動で同梱される（IPA サイズは v0.2.0 より大きくなる）。パッケージは main の特定 revision に固定してあるので、上げる場合は revision を差し替えて再検証すること。
